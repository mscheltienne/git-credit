The minimum supported Rust version (MSRV) is the oldest Rust toolchain git-credit promises to build with, declared as `rust-version` in `Cargo.toml` and checked by a CI job pinned to that exact toolchain.

Covered in: [The MSRV pin](../Development/03%20Linting%20and%20CI.md#the-msrv-pin)
