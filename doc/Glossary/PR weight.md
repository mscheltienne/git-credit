A PR weight is the `(author, additions, deletions)` triple git-credit computes for one PR commit from GitHub's per-file stats, excluded files left out. Weights only set the proportions of the [proportional split](Proportional%20split.md); the lines split are the squash commit's own.

Covered in: [Weighing the authors](../Attribution/03%20PR%20Expansion%20and%20Split.md#weighing-the-authors)
